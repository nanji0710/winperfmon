# 隐私与安全声明（面向用户）

> 产品名 **winperfmon**（已定）· 状态：**设计稿 v1**（随首次发布生效；若与实现不符，以实现为准并在发布前修正本文件）。
> 关联：`release-github.md` §9（合规要点）、`architecture.md`（进程与权限模型）、`winperfmon-dev-plan.md` §9（反作弊处理）。

## 一、一句话结论

**不联网、不采集、不注入、不挂钩；Ring0 驱动可选且可完全禁用；所有数据只存在于本机内存与你自己的本地文件里。**

## 二、网络行为

| 项 | 承诺 |
|---|---|
| 遥测 / 崩溃上报 / 账号 | **无**。程序不自带任何上传路径 |
| 默认联网 | **不使用网络**。断网运行全部功能（除手动"检查更新"）均可用 |
| 可选"检查更新" | 默认**关闭**；仅在用户主动点击后向 GitHub Releases 发起一次 HTTPS 请求，不携带任何机器标识 |
| 编译期开关 | 提供 `WPM_NO_NETWORK=1` 构建"绝不联网"版本（源码级剔除检查更新代码），供企业与洁癖用户自建 |
| 为什么不内置下载 PresentMon / PawnIO | 内置下载＝引入联网行为，与本声明冲突；只在 UI 与 README 给出官网链接与安装指引 |

**可自证方式**（任何人可复核）：① 仓库全文检索无网络调用（`git grep -i "winhttp\|wininet\|socket\|curl"`，仅允许出现在默认关闭且可编译期移除的检查更新模块）；② Release 附带 `SHA256SUMS.txt` 校验产物；③ 断网运行。

## 三、进程与系统交互（不注入、不挂钩）

- **不向任何进程注入 DLL**，不安装 API 钩子，不使用低级键盘钩子（热键走 `RegisterHotKey`），不修改游戏或驱动的任何文件，不读游戏进程内存。
- **FPS 采集**：走 Intel PresentMon 官方服务（ETW 由它以 SYSTEM 权限采集），本项目只**只读消费**其 API 暴露的帧数据。
- **覆盖显示（Overlay）**：用置顶透明窗口（分层窗口 + 逐像素 alpha）实现，不进入游戏进程。
- **RTSS OSD 后端（可选）**：本项目只向 `RTSSSharedMemoryV2` 共享内存写入文本，**注入由 RTSS 自身完成** —— 这一点在 UI 与 README 中如实说明，不含糊、不掩盖。
- **反作弊场景**：检测到受保护进程时**不触碰其进程**，自动降级为 GPU-only 读数 + PresentMon FPS；不保证在所有反作弊环境可用。

> **决策 ③=B 更新：** PawnIO 官方安装包随发布包附带，由本程序在首次运行时**引导**用户确认后调用其静默安装（一次 UAC；属内核驱动安装，可拒绝，拒绝即落免驱模式）。我们不修改、不重签名该二进制；卸载 winperfmon 时默认**不移除** PawnIO。

## 四、Ring0 与权限

- 本项目**不自带内核驱动**。需要 CPU 温度 / 功耗 / 主板风扇转速时，由**用户在明确确认后安装** PawnIO（第三方、GPL-2.0、已签名；官方安装包随发布包附带，可拒绝）；本项目只在用户态向它发起 IOCTL。
- **只读语义**：只读 MSR / 端口 I/O / SMN；除"向 SMU 邮箱投递查询命令"这一必要的间接读外，不发送任何控制命令；命令号白名单固定在代码内（不从可热更新的数据包加载）。
- **可完全禁用**：设置中一键关闭 Ring0 → 进入**免驱模式**（CPU 温度/功耗/主板风扇显示 `N/A`，并在界面解释原因）。禁用后不打开任何设备句柄。
- **权限**：v1 单进程形态需要管理员权限（读 MSR/端口）；v2 拆分为 `pmsvc`（SYSTEM 服务）+ `pmui`（普通权限 UI）后，UI 与 Overlay 不再提权。

> **决策 ④=B 更新：** 主路径为 RTSS OSD 共享内存后端：winperfmon 只写 `RTSSSharedMemoryV2`，**注入由用户自行安装的 RTSS 完成**，本程序不注入任何进程。选择 RTSS 模式意味着接受 RTSS 对游戏进程的注入及其反作弊/稳定性风险（由 RTSS 承担）。

## 五、本地数据与文件

| 数据 | 位置 / 行为 |
|---|---|
| 配置 | `%APPDATA%\winperfmon\config.json`（便携模式下为 EXE 同目录）；内含**仅显示偏好**，不含硬件指纹、不含使用统计 |
| 日志 / CSV | 仅在用户显式开启或点击导出时写本地；默认不写盘、不轮转 |
| 导出内容 | 不含机器名、用户名、序列号、GPU UUID、IP、含用户名的路径（或提供"匿名化"开关） |
| 诊断输出（`--probe`） | 为社区提交 Super I/O 芯片表而设计，可能包含主板 DMI 字符串、芯片 ID、端口探测结果与原始计数；**提交前必须提示用户检查并删除可识别信息**（格式与字段清单见 `contributing-sensors.md` §3 与 §5） |

## 六、安装、卸载与残留

- 首版**不安装服务、不安装驱动**（portable 单 EXE + zip）；因此不存在"后台常驻组件"。
- 卸载：删除 EXE 与 `%APPDATA%\winperfmon\`；若用户勾选过"随系统启动"，该项可在设置中取消（不写其它注册表位置）。
- 若用户**自行**安装过 PawnIO，卸载本工具**不会**删除它（其他硬件监控工具可能依赖），并在卸载提示中说明。

## 七、已知限制与免责

- 读数为**参考值**，不用于质保申诉、超频安全决策或硬件故障判定。
- 笔记本、虚拟机、部分主板不暴露全部传感器 → 显示 `N/A` 并给出原因，**绝不填假值**。
- 兼容性：Windows 10 1809+ / Windows 11；开启 HVCI（内存完整性）时，仍需安装 PawnIO（GPL-2.0，官方安装包随发布包附带、由用户确认后安装）才能读取 MSR；其 `.bin` 模块来自 PawnIO.Modules（LGPL-2.1），模块由谁提供尚在核实（见 `release-github.md` §3.5）。
- 真独占全屏（legacy FSE）下**自绘**非注入 Overlay 无法显示（决策 ④=B：主路径改为 RTSS OSD 共享内存后端，**注入由用户自行安装的 RTSS 完成**）；非 FSE 场景的置顶窗口可能把游戏从 `Hardware: Independent Flip` 降级为 `Composed: Flip`（增加延迟、影响 VRR）——程序会自检并提示（见 `fps-metrics.md` §3）。
